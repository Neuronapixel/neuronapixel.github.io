# Branch Naming Conventions

This project follows industry standard branch naming practices to keep the repository organized.

- **feature branches**: `feat/<short-description>`
- **bug fixes**: `fix/<short-description>`
- **documentation**: `docs/<short-description>`
- **refactoring**: `refactor/<short-description>`
- **tests**: `test/<short-description>`
- **maintenance chores**: `chore/<short-description>`
- **codex-generated**: `codex/<type>/<short-description>`

Use `codex/` as a prefix when a branch is created by the Codex agent. Replace
`<type>` with one of the categories above, e.g. `codex/feat/add-login`.

Use lowercase letters and hyphens to separate words. Keep branch names concise and descriptive.
